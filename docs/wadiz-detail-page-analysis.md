## 6. 확인·주의 사항

1. **티태그 주소 오타 (인쇄 전 수정 필수)** — 티태그 뒷면 `www.취향의 권리.com`(띄어쓰기 포함) → 접속 불가. **`취향의권리.com`** 으로 수정
2. **‘카페인 0’ 표현** — 설계서 §18은 “카페인 미확인 표현” 금지. 섹션 4의 ‘0 카페인’과 FAQ “없습니다”는 원료 기준 확인(가능하면 시험성적) 후 사용. 확인 전이면 “허브와 곡물로만 구성” 정도로
3. **VER.2 커피 표현** — “커피처럼 즐기는 곡물 블렌딩”은 설계서 허용 표현. “매일 커피 대신 마실 것을 찾는 분에게”는 ‘대체’로 읽힐 수 있어 “커피를 마시던 시간에 제안하는 새로운 한 잔” 쪽이 안전
4. **명칭 통일** — 시안은 VER.1 HERB / VER.2 GRAIN, 설계서(9/16)는 아로마 / 루트 앤드 그레인 로스트. 패키지·홈페이지·와디즈를 한 이름으로 맞출 것. 원료명도 레이블은 ‘팥’, 시안은 ‘단팥’
5. **원료 구성** — 최종 레이블 12종 기준 VER.2 = 민들레 뿌리·팥·둥굴레·현미·찰수수·보리 (시안과 일치)
6. **이름 공개 동의** — 엘카페 로스터 양진호, 대한명인회 표기 방식 (설계서 §18 운영 정보 확인 항목)
7. **재구매 FAQ** — “취향의권리.com에서 원료만 낱개 구매”는 카페24 쇼핑몰 오픈 일정에 따라 달라짐 (현재 준비중 페이지)
8. **인스타 계정** — 시안 표기 `@right.totaste` 철자 확인
9. **모션** — 와디즈 본문은 GIF 기준. 시안의 GIF 13종은 용량 관리(프레임 수·길이) 필요
