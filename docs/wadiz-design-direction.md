> 전제: **내용·단락 순서는 대표 스토리 시안(아티팩트) 그대로**, **디자인은 전면 교체**.
> 근거: 대표 레퍼런스 7건 + 추가 조사 7건(티·차 밖에서 고름)의 상세 이미지 721장 전수 확인. 시트는 `docs/wadiz-refs/` (A~G 대표 레퍼런스, N1~N7 추가).

> - **상세페이지는 HTML로 제작**한다 (이미지 안에 글자를 굽지 않음). 와디즈 업로드용 이미지는 HTML을 섹션 단위로 캡처해 내보낸다.
> - **이미지는 글자 없이 생성**하고, 글자는 HTML로 얹는다.
> - 이미지 생성은 **품질 기준으로 ComfyUI 우선, 그다음 GPT**.
> - 영상은 **Remotion + 힉스필드**로 제작. 힉스필드는 글자 없는 실사 클립, Remotion은 모션 타이포·그래프·전환. **텍스트와의 조합은 편집 단계에서** 처리한다 (생성 단계에 글자를 넣지 않음).

### 추가 레퍼런스에서 확인한 디자인 기법 (대표 레퍼런스에는 없던 것)

1. **다크 밴드 ↔ 아이보리 교차 리듬** (N1·N2·A) — 브랜드 선언·숫자·리워드는 짙은 배경, 설명은 밝은 배경. 스크롤에 호흡이 생김
2. **노트 카드 모듈** (N1) — 파스텔 카드 + 이탤릭 세리프 영문 라벨 + Top/Mid/Base 3줄 + 제품 누끼 + 꽃 사진에 세로 영문 타이틀. **향 하나마다 색 한 가지**
3. **꽃말 서사** (N1) — “지조, 인내, 절개” *Bamboo* 식으로 원료마다 인용구 한 줄 → 우리 보태니컬 카드(학명 병기)에 그대로 적용 가능
4. **사진 에세이 구간** (N2) — 텍스트 거의 없이 따뜻한 창가 빛 사진 6~8장 연속, 한 줄 카피만. 거창유기는 이 구간이 전체의 40%
5. **키워드 한 단어 강조색** (N2) — 긴 문장 없이 “태초의 **불**이”, “그 **빛**이” 한 글자만 색을 바꿈
6. **큰 숫자 타이포 섹션** (N1 “24시간”, “꼭대기.”) — 대표 시안 4번(12·0·27잔·2)에 그대로 맞음
7. **리뷰 카드 = 실제 집 안 사진 + 연령·성별 태그 + 별점** (N1) — 대표 시안 11번 체험단 후기 형식
8. **두 갈래 인포그래픽** (N6 “빠르고 맛있게 / 깊고 진하게”) — 대표 시안 5·7번 (향긋하게 / 고소하게)
9. **맛 막대 그래프** (N6 단맛·신맛·쌉싸름함) · **레이더 차트** (F) — 원료·레시피 모듈
10. **구성품 번호 다이어그램** (N5) — 대표 시안 3번 키트 실물에 추가
11. **리워드 카드** (N1·A) — 제품 누끼 + 한정수량 배지 + 큰 % 원형 + 취소선 정가. 카드마다 같은 틀
12. **Before/After·과정 사진** (N3·A) — 대표 시안 6번 “따라 해보고 → 바꿔보고 → 나의 맛으로”

### 2-3. 타이포
- 한글 헤드라인: **Noto Serif KR 600** (A·N2처럼 크게, 2~3줄, 행간 1.6)
- 한글 본문: Noto Sans KR 300~400, 16px 이상 (대표 시안 지시 “본문 16px 이상”)
- 영문 라벨: **Cormorant Infant Italic** (N1의 이탤릭 세리프 라벨 역할) — design7과 동일
- 캡션·번호·학명: **Courier Prime** 타자기체 — 브랜드 고유, 패키지 “the right to taste”와 연결
- 큰 숫자: Cormorant 300, 96~120px

### 2-4. 이미지 규격
- 가로 **860px** 작업 → 와디즈 업로드 기준에 맞춰 내보내기 (대부분의 레퍼런스가 800px급)
- 전체 25~35장. 사진 에세이 구간은 세로 긴 장 1장으로 묶기
- GIF: 800px, 3~4초, 24fps 이하, 5MB 이하 (와디즈 본문 모션 기본)

## 4. 제작 방식 — HTML 상세페이지 + 글자 없는 이미지

### 4-1. 구조
- 상세페이지 전체를 **HTML 한 페이지(860px 고정폭)** 로 만든다. 텍스트·숫자·카드 테두리·막대 그래프·점(●) 비율 표시·QR은 전부 HTML/CSS/SVG.
- 이미지는 **배경·사진·일러스트만** 담는다. 글자가 들어간 이미지는 만들지 않는다 → 문구 수정이 생겨도 이미지를 다시 만들 필요가 없고, 시음 확정 후 숫자(27잔·비율·℃)만 고치면 된다.
- 와디즈에 올릴 때는 HTML을 **섹션 단위로 캡처**(860px → 와디즈 규격으로 축소)해 이미지로 업로드. GIF 구간은 GIF 파일 그대로.
- 폰트: 홈페이지(design7)와 같은 웹폰트(Noto Serif KR · Noto Sans KR · Cormorant Infant · Courier Prime) → 캡처해도 홈페이지와 글꼴이 같다.

### 4-2. 소재 제작

| 구분 | 내용 | 도구 (우선순위) |
|---|---|---|
| 누끼 촬영 (1회) | 박스·아코디언북·원료 12종(유리병)·스쿱·공티백·노트·인퓨저·단팥차 샘플·엽서·종이가방·티태그 | 실물 촬영 |
| 연출 이미지 (글자 없음) | 누끼 위에 미장 벽·창가 빛 배경 합성: 구성품 배치컷, 비교 두 잔(A-1/A-2), 곡물 클로즈업(C), 리워드 제품컷, 선물 패키지, 사진 에세이 컷 | **① ComfyUI → ② GPT** (품질 기준으로 선택) |

## 5. 목요일 초안 산출물

1. **HTML 상세페이지 초안** (`wadiz/index.html`, 860px) — 대표 시안 16섹션 순서 그대로, 글자는 전부 실제 텍스트, 이미지 자리는 기존 GIF·스틸 + 글자 없는 placeholder
2. 디자인 시스템이 HTML 안에 포함 (CSS 변수: 컬러·타이포·카드 모듈 3종: 원료 노트 / 레시피 / 리워드)
3. 완성도 높은 **대표 섹션 3개**: 히어로+이벤트 띠 / 원료 노트 카드(HERB 1장·GRAIN 1장) / 리워드 카드 — 대표가 톤을 승인할 기준점. 이 3개는 ComfyUI/GPT 연출 이미지까지 넣어서
4. 레퍼런스 보드: `docs/wadiz-refs/` 14장 중 A·N1·N2·N6 발췌
