### 소재·표면
- 전 면 **밝은 아이보리 미장(석회 플라스터) 텍스처**를 실사 프린팅. 텍스처 원판 `data/KakaoTalk_20260814_193832786.png`(1055×1491), `_01.png`. 7월의 고재(나무결) 방향은 8월에 이 방향으로 교체됨.
- 글자·엠블럼은 다크 브라운 1색(톤온톤). 박스 라벨 서체는 타자기체.
- 아코디언 내지는 흰 종이 질감(미장보다 밝음).

> **⚠ 10/19 실물 촬영본으로 정정** (`docs/촬영-분석.md` §2): 실물은 슬리브+트레이가 아니라 **원피스 메일러 박스(롤엔드 턱탑, 속면 흰색) + 중앙 디바이더 1장(좌우 2칸)** — 왼칸 아코디언북(띠지), 오른칸 블렌딩 노트. 아코디언북은 파우치 면 ↔ 아치형 엽서 창 면이 교대, 엽서는 꺼낼 수 있다. 아래 "전개도 기준" 해석과 3D 스모크 테스트는 이 구조로 다시 잡아야 한다.

### 구조 해석 (전개도 기준 — 실물과 다름, 위 정정 참고)
- **슬리브 + 트레이 2피스**: 트레이(285×275×75)가 슬리브(305×289×75) 안으로 들어가는 서랍/슬라이드 구조. 슬리브 걸쇠는 전면 중앙 1곳.
- 트레이 안에 **아코디언북이 눕혀 들어감**: 접힌 상태 130×180mm(+커버 두께). 바닥 285×275 안에서 아코디언 옆 공간(~150×275)에 파우치 6개 + 도구가 놓이고, 그 위에 소형 트레이(177×129×60)가 도구 칸으로 얹힐 수 있는 치수.
- 7월 합의대로 "하드커버 박스 안에 아코디언이 용수철처럼 딸려나오는 구조"는 유지, 다만 하드커버 박스 대신 **슬리브+트레이 인쇄 지기**로 단순화된 것으로 보임.

### 확인이 필요한 것 (대표·디자이너)
1. 소형 297×249 전개도의 **용도**(도구 트레이? 선물 포장 옵션 상자?)와 트레이 안 배치.
2. 띠지 문구가 **Taste/Depth 구 명칭** — VER.1 HERB / VER.2 GRAIN으로 바꿀지.
3. 트레이 안쪽 플랩·티태그의 `www.취향의 권리.com` 띄어쓰기 → `취향의권리.com`.
4. 판지 두께(E골 1.5mm? 합지 2mm?) — 전개도에 두께 보정이 없어 인쇄소 확인 필요. 3D는 1.5mm로 가정.

## 2. Blender 3D 모델링 가능성 — **가능 (검증 완료)**

| 항목 | 결과 |
|---|---|
| Blender | **5.2.1 LTS** 설치됨 (`C:\Program Files\Blender Foundation\Blender 5.2\`). Higgsfield Blender 브리지(bl_* MCP)는 미연결 → **헤드리스 `blender -b --python`** 으로 직접 구동 |
| 도안 → 치수 | 전개도 PDF가 **벡터**라 선 좌표를 그대로 읽어 패널 치수 추출 가능(위 표의 측정값이 그 결과). 칼선/접선이 같은 2pt 실선이라 구분은 위치로 판단 |
| 텍스처 | 전개도 PDF를 고해상 래스터화(300dpi)하면 그대로 UV 텍스처로 사용 가능. 글자·엠블럼 포함 |
| 스모크 테스트 | `blender_box_test.py` — 측정 치수로 트레이·소형 트레이·아코디언 12면 자동 생성, EEVEE 렌더 **22초**(1400×900). 결과 `09_blender_테스트렌더.png`, 씬 `box_test.blend` (24 오브젝트). 카메라 프레이밍은 아직 거칠다(가능성 확인용) |

### 권장 제작 경로
1. **치수 스크립트화**: 전개도 좌표를 JSON으로 저장 → 파이썬이 메시 생성(이미 패턴 확보). 슬리브(걸쇠 포함)·트레이·소형 트레이·아코디언 커버 추가.
2. **UV 매핑**: 전개도 PDF를 300dpi PNG로 렌더 → 각 패널 면에 전개도 좌표 그대로 UV 지정(라벨 위치가 자동으로 맞음). 미장 질감은 노멀/범프 맵으로 살짝.
3. **아코디언 리깅**: 패널 12면을 힌지 체인(Empty 부모 + Z 회전)으로 묶으면 "용수철처럼 딸려나오는" 펼침 애니메이션 가능 → 와디즈 GIF·힉스필드 참조 프레임.
4. **출력**: 언박싱 턴테이블 영상(와디즈 s03 키트 실물), 구성품 플랫레이(생성 이미지 대체), 패키지 3면도.
5. 시간 예상: 치수·메시 1일, UV·재질 1일, 조명·카메라·애니 1일.

### 제약
- 전개도에 **지기 두께·접힘 여유가 없어** 조립 시 간섭은 3D에서 임의 보정(1.5mm).
- 파우치·공티백·티스푼·책은 원고가 없으므로 기성 형태로 따로 모델링.
- Blender MCP(실시간 제어)를 쓰려면 Higgsfield 플러그인을 Blender에 연결해야 함. 지금은 스크립트 배치 방식으로 충분.
