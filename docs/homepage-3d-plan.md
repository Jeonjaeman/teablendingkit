## 1. 한 줄 방향

**"스크롤하면 상자가 열리고, 멈추면 바로 고르고 산다."**
한 페이지 스크롤 사이트. 가운데 3D 키트가 스크롤에 따라 돌고·열리고·구성품이 하나씩 나오며, 화면 모서리에는 **취향 찾기 · 키트 보기 · 구매** 버튼이 항상 떠 있다. 글은 짧고 2인칭, 판매 문구는 버튼에만.

대표가 정한 원칙 중 지키는 것
- 정답을 주지 않는다 → 진단 결과도 "추천"이지 "정답"이 아니라고 적는다.
- 상품이 아닌 경험 → 상단 2/3는 상자를 여는 경험, 가격·구매는 하단과 고정 버튼으로.
- 티아포테카와 분리된 독립 브랜드, 문의는 카카오 채널.
- 모바일에서 길어도 흐름이 끊기지 않으면 된다(대표 동의).

```
┌─────────────────────────────────────────────┐
│ 로고          [취향 찾기] [키트 보기] [구매] │ ← 고정 상단(항상)
│                                             │
│            ┌──── 3D 키트(고정 캔버스) ────┐  │
│   텍스트    │  스크롤 진행에 따라 변함     │  │ ← S1~S7 동안 캔버스는 화면에 고정,
│   (좌/우    │                             │  │    글만 흘러감(pinned scene)
│    교대)    └─────────────────────────────┘  │
│                                             │
│ ●●●●○○○ 진행 점(섹션 이동)          ↑ 위로 │ ← 고정 하단
└─────────────────────────────────────────────┘
```

- 3D 캔버스 1개를 `position: fixed`로 두고, 섹션마다 **카메라·상자 상태·구성품 위치**를 바꾼다. 스크롤 양 = 애니메이션 진행도(GSAP ScrollTrigger scrub).
- 글은 섹션마다 좌·우 교대로 짧게. 큰 제목 한 줄 + 본문 두 줄 이내.
- 모바일: 캔버스를 상단 55vh에 고정, 글은 아래로 흐름. 저사양이면 3D 대신 **미리 렌더한 프레임 시퀀스(이미 Blender로 만든 언박싱 145프레임)**를 스크롤로 넘긴다.

## 3. 스크롤 연출 순서 (3D 시퀀스)

Blender 모델(`3d/kit_scene.py`: 상자·뚜껑·칸막이·아코디언북·띠지·노트 / `3d/flatlay_scene.py`: 파우치·일러카드·스쿱 종이·엽서·인퓨저)을 GLB로 내보내 그대로 쓴다. 구성과 순서는 **와디즈 언박싱 v1.10 확정 순서**와 같다.

**소품 클릭 연출 (10/23 전재만 결정: 병풍·노트는 스크롤 안에 넣지 않고, 플랫레이(S6·S7)에서 소품을 클릭하면 따로 보여 준다)**
- 스크롤은 멈추고(본문 overflow hidden) 카메라가 소품으로 이동, 소품이 연출된 뒤 「돌아가기」·Esc·빈 곳 클릭으로 원래 자리·카메라로 돌아온다. 스크롤 카메라와 소품 카메라를 한 값(F.t)으로 섞으므로 끊김이 없다.
- 아코디언북 → 플랫레이 책이 줄어들고 힌지 아코디언이 앞 무대에 서서 병풍처럼 펼쳐짐(접힘각 88°→30°, 12면 + 파우치 창 6). 노트 → 힌지 노트가 앞에 서고 표지 → 내지 3장 차례로. 파우치 → 들려 기울고 이름·향 노트. 인퓨저 → 들려 천천히 돈다. 엽서 → 부채꼴이 더 벌어짐. 허브 스티커·종이 스쿱 → 들려 기울어 위에서.
- 클릭 가능 표시: 플랫레이가 다 펼쳐지면 각 소품의 (위에서 본) 오른쪽 위 모서리에 작은 「+」 태그가 뜬다(물건을 가리지 않음, 호버하면 이름). 소품 위에 마우스를 올리면 시스템 손가락 커서 대신 「보기」 원형 커서가 따라다니고 이름·향 노트 툴팁이 붙는다(연출 중에는 「닫기」). 태그를 눌러도, 소품을 직접 눌러도 같은 연출.
- 글 상자는 클릭을 가로채지 않는다(버튼·토글만 받음).
- 상자 안 오른칸은 노트(간지 위, 두께 11mm) → 종이 스쿱(비스듬히 30°, 모서리가 비어져 나옴) → 허브 스티커 순으로 쌓여 보이고, 스티커부터 들려 나온다.
- 치수 정합(10/23 정밀 점검): 칸 안쪽 136×205×71mm(바닥 윗면 y 2.6, 칸막이 70.6). 노트 126×174×11은 y 53.3~64.4. 그 위 스쿱(104×146, 뒤·오른쪽으로 어긋나게, 3°) → 스티커(116×166, 앞·왼쪽으로) — 모두 칸 안에 들어가는 오프셋만 쓴다(돌리면 벽을 뚫음). Blender 렌더용 받침 `note_riser`는 숨기고 그 자리에 간지(y 52)·인퓨저(211mm → 칸에는 25° 대각선, .88배, 바스켓 Ø56이 간지 밑에 들어가도록)·단팥차 샘플(74×84, 칸 왼쪽 앞)을 실제로 넣었다. 꺼낼 때 책·단팥·인퓨저는 벽(74)·칸막이 높이보다 높게 들어 올린다(arc ×1.3/×1.6). 간지는 왼칸 바닥에 0°로(128 < 136).
- 인퓨저 모델은 손잡이가 아래로 처진 형태(그룹 중심 기준 가장 낮은 점 −23.4mm) → 추가 기울임 없이 중심 높이로만 접지(플랫레이 24.9mm, 바닥 위 1.5mm). 상자 안은 .82배·32° 대각선(벽에서 15mm 이상, 꼭대기 43mm < 간지 52).
- 파우치 순서는 GLB 노드 순서가 아니라 명시 배열(ORDER_T/ORDER_D)로 고정 — 1줄 빈 티백·레몬밤·캐모마일·히비스커스, 2줄 페퍼민트·유자·장미. Depth 전환 때 빈 티백만 남는다.
- 엽서 6장은 파우치처럼 아코디언북에서 한 장씩 빠져나와 부채꼴로(와디즈 언박싱 영상과 같게).
- 인퓨저: 바스켓 두 반구에 점무늬 알파맵 컷아웃(alphaTest)으로 구멍을 뚫었다(간격 ≈4.5mm·지름 ≈3.2mm, 실물보다 조금 크게 해야 화면에서 읽힘). 연출 중 천천히 돌고 돌아올 때 제자리 각도로 복귀.

움직임 규칙(대표 "과한 움직임 지양")
- 스크롤을 멈추면 모든 것이 멈춘다. 자동 재생 없음. 흔들림·바운스 없음.
- 한 섹션에서 바뀌는 것은 한 가지(카메라 **또는** 물체).
- 조명은 와디즈 연출 컷과 같은 오후 햇빛 + 잎 그림자 고정.

## 5. 취향 진단 흐름

이미 만든 `shared/taste-test.js`(8문항 · 4유형 · 개인정보 수집 없음)를 그대로 쓰고, 보여 주는 방식만 바꾼다.

```
[취향 찾기] 클릭
  → 오버레이 열림. 뒤의 3D는 흐리게 남김
  → Q1~Q8: 한 화면에 질문 1개, 선택지 4개(카드), 위에 진행 막대 "3 / 8"
     · 선택 즉시 다음 문항(버튼 없음), 뒤로 가기 화살표
     · 선택지는 그림 없이 글만 — 원료 사진은 결과에서 보여 준다
  → 결과: 유형 이름 + 한 줄 설명 + 추천 키트 + 첫 레시피(원료 3개 비율)
     · 뒤의 3D가 **추천 키트 상태로 바뀐다** (A·B → Taste 파우치, C → Depth, D → 2개 세트)
     · 버튼 1 "추천 키트 자세히 보기" → 오버레이 닫고 S8에서 그 키트가 선택된 상태
     · 버튼 2 "다른 취향도 발견하기" → 다시 시작
     · 공유: URL에 ?result=A 로 결과 공유(이미 구현됨)
```

- 결과 문구에 "정답이 아니라 첫 번째 기준입니다. 한 번 맛본 뒤 반 스푼씩 바꿔 보세요." 한 줄을 넣는다(9/16 §3).
- 진단 데이터는 저장하지 않는다. 완료 수만 집계(선택).

참고한 화면(Mobbin): Mindtrip 퀴즈(큰 사진 + 질문, 슬라이더), UNIQLO 온보딩(1/3 진행 + 복수 선택 카드), Codecademy 결과(유형 이름 + 다음 행동 버튼), Square 추천 결과(BEST MATCH 배지 + 바로 담기).

S8 카드 구성: 3D 상자 1개씩 + 이름 + 원료 6종 + 가격 + 버튼. 선택한 카드가 앞으로 나오고 나머지는 뒤로. 세트 카드에는 "Taste와 Depth를 함께 갖고 있을 때 교차 블렌드까지" 한 줄.

결제 방식은 미정이다.
- **A. 카페24 쇼핑몰에 결제 위임**: 홈페이지는 랜딩, 구매 버튼이 카페24 상품 페이지로 이동. 구축이 빠르고 회원·주문 관리가 쉽다. 도메인은 이미 카페24 DNS.
- **B. 자체 결제(토스페이먼츠 등)**: 페이지 이탈 없이 끝나지만 주문·배송·CS 관리 화면을 따로 만들어야 한다.
- 추천: 펀딩 중에는 와디즈 링크, 종료 후 **A**. 회원 가입은 카페24 쪽에서 받아 "회원이 자산"(대표)이라는 바람과 맞춘다.
