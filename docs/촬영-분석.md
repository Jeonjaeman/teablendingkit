## 2. 실물로 확정된 패키지 구조 (전개도 해석 정정)

`docs/package-spec/README.md`에서 전개도만 보고 "슬리브+트레이 2피스"로 추정했는데, **실물은 다르다.**

| 항목 | 실물 |
|---|---|
| 겉박스 | **원피스 메일러 박스(롤엔드 턱탑)** — 뚜껑이 뒤쪽 힌지로 열리고 앞 혀를 꽂아 닫음. 겉 전면 미장 인쇄, **속면 흰색**. 바닥·벽 안쪽에도 미장 인쇄 |
| 칸막이 | 박스 중앙 **세로 디바이더 1장**(겉 다크브라운/속 흰색, 엄지 구멍) → 좌우 2칸 |
| 왼칸 | 아코디언북(하드커버, 앞표지 사진) + 띠지 |
| 오른칸 | **블렌딩 노트(소프트커버)** — 대표 확인(10/20). 촬영 때는 노트를 꺼내 넘기는 중이라 비어 있음 |
| 아코디언북 | 하드커버, 접힌 두께 ~4cm. 펼치면 **파우치 면 ↔ 엽서 면 교대**. 파우치 면은 흰 바탕에 사선 칼선 4곳으로 글라신 파우치(로고 라벨 + 원료) 고정. 엽서 면은 **아치형 창**으로 엽서 앞 사진이 보이고 옆에 영문 타이틀·한글 시 |
| 엽서 | 세로형 6종, 아코디언 창에 끼워져 있다 꺼낼 수 있음. 뒷면이 원료 카드(AROMA·NOTE·BREW·TODAY) |
| 띠지 | Taste(올리브)·Depth(다크브라운) 2종 — 아코디언북에 두름 |
| 블렌딩 노트 | 소프트커버, 질문형 에세이 + 기록 괘선 + 사진 스프레드 |

→ 전개도의 648×609 대형 도면은 메일러 박스 본체, 297×249 소형 도면과 1918×610 그래픽 도면 안의 패널들은 칸막이·노트 커버 쪽으로 다시 대조해야 한다. **3D 모델은 메일러 박스 + 디바이더 구조로 다시 잡는다.**
