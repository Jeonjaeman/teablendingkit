## 1. 자스민영 문법 → 우리 적용

| 자스민영 | 적용 |
|---|---|
| 순백 ↔ 연세이지 면 교차 | `--white #FFFFFF` ↔ `--sage-bg #EEF3E8`. 사진 섹션 풀폭 |
| 산세리프 가운데 정렬, 두 줄 중 한 줄만 **올리브 박스 흰 글씨** 또는 **두꺼운 밑줄** | Noto Sans KR 500/700, 26~34px. `.box`(배경 `--olive #7A8B5E`, 흰 글씨, 패딩 4px 14px) · `.ul`(`text-decoration: underline 3px --olive`, `text-underline-offset 8px`) |
| 핵심 단어 위 점 세 개 | `.dots` — `::before` content "···" 위에 작게 |
| 섹션 구분 원 3개(연→진) | `.sep` 세 원 `--sage-1 #D8E3CC` `--sage-2 #AFC19C` `--olive` |
| 테마색 제품 모듈 ×5 | **×3**: VER.1 HERB = 로즈 `--t1 #D9A5A5` / 연 `#F4E3E3`, VER.2 GRAIN = 오커 `--t2 #B08F63` / 연 `#F0E6D4`, TWO KIT SET = 세이지 `--t3 #8FA08A` / 연 `#E4EBDF` |
| 원료 화환 플랫레이 | `gen/wreath_herb.png` · `gen/wreath_grain.png`(원료를 둥글게 둘러 놓은 오버헤드, 가운데 빈 자리에 **박스 사진이 아니라 HTML 라벨 카드**를 얹는다 — 파우치 대신 우리는 상자) |
| 6축 레이더 | SVG 6축: 향기·산미·달콤함·바디감·고소함·상쾌함, 테마색 채움 35% |
| 원료 칩 그리드 | 원형 마스크 `real/ing_*.png` + 이름 + 알약 "학명" + 라틴 학명 한 줄(성분 대신 **학명**) 2열 |
| "이런 분들께 꼭! 추천드려요" 밴드 + 체크 카드 | 테마색 밴드 + 흰 카드 체크 4줄(product-data.js `for_`) |
| 리뷰 카드(별·아이디·굵은 제목·본문·사진) | **가짜 후기 금지** → 같은 카드 틀로 "체험단 20명의 첫 잔 이야기를 이 자리에 싣습니다" 3장 + 스틸 |
| 연구팀 라벨 3개 | 2개: 차 블렌딩명인 · 로스터 |
