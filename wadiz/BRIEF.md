# 와디즈 상세페이지 HTML 초안 — 제작 브리프 (3종 공통)

작업 폴더: `wadiz/`. 산출물 3종: `a-essay.html` · `b-notecard.html` · `c-fieldnote.html` (각각 완결된 단일 HTML, 외부 JS 라이브러리 없음, CSS는 `<style>` 인라인).
참고 문서: `docs/wadiz-design-direction.md`(디자인 방향), `docs/wadiz-detail-page-analysis.md`(레퍼런스 분석), 레퍼런스 시트 `docs/wadiz-refs/*.jpg`.

## 0. 절대 규칙
1. **페이지 폭 860px 고정** (`.page{width:860px;margin:0 auto}`), 바깥 배경은 `#EDE8DF`. 모바일 대응 불필요(와디즈 업로드용 캡처 원본).
2. **글자는 전부 HTML 텍스트.** 이미지에 글자를 넣지 않는다. 숫자·그래프·점(●) 비율·배지·QR 프레임은 HTML/CSS/SVG로.
3. **카피는 아래 §3 문구를 그대로** 쓴다(오타 수정 외 임의 변경 금지). 단 §4의 표현 가드는 적용.
4. 없는 이미지는 `<div class="ph" data-shot="…">` 플레이스홀더로. 플레이스홀더 안의 라벨(예: "새로 촬영 A-1 · 왼쪽 잔 연한 노란빛")은 **HTML 텍스트**로 작게 표기 — 이것은 작업용 표시이며 `.ph` 스타일은 점선 테두리 + 연한 배경.
5. 기존 영상 GIF(조인젠블렌드)는 아직 로컬에 없다 → 비슷한 분위기의 `assets/photo/*.jpg`를 대신 깔고 `data-gif="03_창가독서.gif"`처럼 교체할 파일명을 속성으로 남긴다.
6. 폰트: Google Fonts `Noto Serif KR(300;400;600)`, `Noto Sans KR(300;400;500)`, `Cormorant Infant(300;400;500;ital 300;400)`, `Courier Prime(400;ital)`. 한글 본문 16px 이상, `word-break:keep-all`.
7. 섹션 id는 `s01`~`s16`(+`s08b` 취향찾기). 각 섹션 최상단에 `<!-- 섹션 N · 제목 -->` 주석.
8. 색은 CSS 변수로만: 아래 토큰 사용. 원색·형광·그라데이션 배지 금지. 판매·회사 언어(회사소개, 구매하세요 류) 금지 — 카피는 §3 그대로.
9. 페이지 맨 끝에 작게 `<footer class="meta">초안 X · 2026-10-20 · 이미지는 placeholder</footer>`.

## 5. 세 가지 스타일

### A · `a-essay.html` — "사진 에세이" (예키맘 A · 거창유기 N2)
- 여백 최대, 세리프 헤드라인 크게(34~40px, 행간 1.7), 본문 짧게. 풀블리드 사진이 페이지의 절반 이상.
- 다크 밴드(`--dark`)와 아이보리 교차. 밴드 안 글자는 `--paper`.
- 사진 사이에 텍스트 없는 사진 1~2장 끼워 호흡(s03→s04, s09→s10, s12→s13).
- 키워드 한 단어만 포인트색(`--grain`)으로: "정답", "비율", "취향".
- 카드류(원료·레시피·리워드)는 테두리 없이 종이 위에 얇은 헤어라인만.
- 섹션 사이 작은 엠블럼(`emblem.svg`, 18px) 구분자.

### B · `b-notecard.html` — "노트 카드 아카이브" (티어 N1 · 노가 B · 티테일 N6)
- 정보 설계형. 모든 모듈이 카드: 원료 노트 카드 12장(보태니컬 + 이탤릭 영문 라벨 + 막대 3개), 레시피 카드(점 비율), 리뷰 카드(태그), 리워드 카드(큰 % 원형 배지, 취소선 정가, 한정수량 배지).
- 버전마다 색 밴드: HERB = `--herb-soft` 배경 + `--herb` 라벨, 장미 계열 원료는 `--rose`; GRAIN = `--grain-soft` + `--grain`/`--brown`.
- s05 상단 **두 갈래 인포그래픽**(SVG: 가운데에서 좌우로 갈라지는 선, 왼쪽 "향긋하게 HERB" 오른쪽 "고소하게 GRAIN").
- s08b 레이더 차트 SVG 강조. s04 숫자는 다크 밴드 + Cormorant 120px.
- 영문 라벨은 세로 회전 텍스트(`writing-mode:vertical-rl`)로 카드 옆에 한 번씩.

### C · `c-fieldnote.html` — "필드 노트 / 타자기" (니들북 N4 · 미꽃체 N3 · 브랜드 타자기체)
- '블렌딩 노트를 펼쳐 읽는' 구성. 종이 질감(`plaster-2.jpg` 얼룩) 위에 타자기체 라벨·번호·괘선·스탬프 느낌의 둥근 테두리 라벨(`.stamp`: 1px 테두리, 살짝 회전 -3deg).
- 헤드라인 세리프, 보조 텍스트 타자기체. 번호 `No.01`~`No.16`을 섹션마다 타자기체로.
- 사진은 폴라로이드/테이프 느낌(흰 여백 + 살짝 회전 ±2deg) — 단 풀블리드 GIF 자리는 그대로.
- s08 레시피 카드는 노트 기록 양식(괘선 표 + 손으로 적듯 점 ●). s09 기록 섹션이 이 스타일의 중심.
- 색은 `--ink`·`--gray`·`--brown` 위주, 포인트 최소.
