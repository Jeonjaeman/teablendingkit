# 스마트스토어 상세페이지 (취향의 권리 티블렌딩 키트)

근거: `원고/취향의 권리 티블렌딩 키트 스마트스토어 상세페이지 원고.pdf` (2026-11-06, 이소연)
톤: 와디즈 E안(`wadiz/e-editorial.html`) CSS를 그대로 가져와 원고 순서로 섹션을 다시 배치. 가격·펀딩·인물 소개 없음, 버전명 Taste/Depth, 효능 문구 없음.

- `body.html` — 본문 마크업(E안 클래스 그대로). 문구 수정은 여기서 한다.
- `build.py` — E안 `<head>`·CSS + body.html → `detail.html`. `python smartstore/build.py`
- `export.py` — 688px 레이아웃을 1.25배로 찍어 가로 860px, GIF 자리에서 끊어 `out/`에 순서대로(세로 5,000px 넘으면 섹션 경계에서 분할). `python smartstore/export.py`
- `out/` — 업로드 순서 01~07(정지 4장 + GIF 3개, 모두 20MB 이하). `out/still/`은 쿠팡용 GIF 정지컷.
- `gif/` — 영상에서 뽑은 GIF 원본. `img/` — 사용 사진(실물 촬영본만). `자료/`(git 제외) — 카톡 공유 영상·비하인드 사진 원본.
