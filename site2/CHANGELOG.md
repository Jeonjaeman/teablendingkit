# site2 — 취향의 권리 공식 홈페이지 변경 기록

버전은 git 태그 `site2-vX.Y`로 찍는다. 수정 요청서 원본은 `site2/docs/수정요청/`에 날짜 순으로 둔다.

## v1.1.1 — 2026-10-25 · 디자인 점검(전 페이지 · 데스크톱 1440 / 모바일 390)
측정 스크립트(넘침·그리드 정렬·이미지 비율·글자 크기·클릭 영역·소수점 위치·hover 변화)와 육안 점검으로 고친 것.
- **버그**: 강사 페이지 탭 패널의 활성 클래스가 스크롤 등장(.rv.on)과 겹쳐 두 폼이 동시에 보이던 문제 → `.act`로 분리.
- **넘침**: 모바일 원료 페이지 가로 스크롤 350px(두 잔 사진 max-width 인라인) · 구매 안내 반블리드 사진 7px 넘침 → 제거.
- **간격**: 버튼 묶음 사이 0px(인라인 스페이서) → `.more`/`.acts` flex gap 14px. 섹션 리듬 72px, 버튼 높이 56px(소 42px)로 통일.
- **hover**: 왼쪽 엠블럼(반전) · 레일 Shop/메뉴/Page top · 히어로 로고 · 카드(사진 1.035배 + 제목 올리브) · 본문 텍스트 링크(밑줄 진해짐) · 레시피 원료 링크 · 강사 탭 · 푸터 링크 — 빠져 있던 것 전부 추가.
- **한글 타이포**: 본문 자간 .04em→.01em, 행간 14/28px 정수. 명조 제목 자간 .08→.05em, h1 26/42px, 소제목 22/36px, 영문 제목 24/32px. 메뉴·내비 자간 .2→.12em, 버튼 .12→.08em.
- **최소 글자**: 태그·상태 배지 10→11px, 필수 표시 9.5→10.5px, 저작권 10→11px, 표 머리 10.5→11px.
- **클릭 영역**: 푸터 링크·입고 알림·레일 버튼에 패딩(최소 28~40px).
- **1px**: 레일 테두리를 안쪽 그림자로 바꿔 메뉴 버튼이 정수 좌표(x=1399)에 놓이게. 모바일 히어로 내비는 숨김(레일·4칸으로 대체), 필터 행은 1열.

## v1.1 — 2026-10-25 · 대표 1차 수정 요청 반영
근거: `docs/수정요청/2026-10-25_1차_홈페이지_수정요청서.pdf` (이소연, Oct 25 2026). 공식 홈페이지는 쇼핑몰 구조인 site2로 가고, site(상자 열어보기 연출)는 와디즈 상세페이지용으로 둔다.

**1. 첫 화면 · 메뉴**
- 커버(고정 화면 + 「1분 취향 찾기」 버튼)를 스크롤되는 히어로로 바꿨다. 작은 문구 「삶은, 끝나지 않는 블렌딩」 → 메인 카피 「직접 고르고 섞는 차, 취향의 권리」(가장 크게) → 서브 카피 「허브·곡물 원료부터 티블렌딩 키트, 교육 재료와 강사 연결까지」 → 버튼 「키트 보기 / 원료 보기」. 모바일에서는 메인 카피 두 줄.
- 히어로 바로 아래 판매 품목 4칸: 원료 · 블렌딩 키트 · 교육 재료·자료 · 강사 연결.
- 메뉴 순서: 원료 · 키트 · 교육 · 강사 · 브랜드 이야기 (보조: 블렌딩 · 구매 안내 · 문의). 홈 히어로 내비·햄버거 메뉴·푸터 모두 같은 순서.
- 「즐기는 법」(enjoy.html)은 키트 페이지 안으로, 「원료 가이드」(guide.html)는 원료 목록·단품 페이지로 합쳤다. 옛 주소는 새 자리로 자동 이동.
- 「1분 취향 찾기」는 레일의 초록 버튼·커버 CTA·메뉴 첫 줄·푸터에서 빼고, 키트 페이지의 보조 도구(「어느 키트가 맞을지 고르기 어려우신가요?」)로 내렸다.

**2. 양진호 로스터 관련 삭제**
- site2: blends.html 메타·소개문·「두 사람의 원칙」 섹션·인물 카드, about.html 마무리 문구(「차 블렌딩의 원칙 위에서」)·링크(「블렌딩 알아보기 →」), shop.html 회사 소개·연혁 제목·Outline 「함께 만든 사람」 행.
- site: index.html 하단 인물 카드, story.html 인물 카드.
- 레시피 이름(브라질리언 로스트 등)은 그대로, 출처·제안자 표기 없음. `yang_jinho.jpg`는 site·site2 어디에도 남지 않음.
- 와디즈 상세페이지(`wadiz/e-editorial.html` v1.10 인물 블록, a~i 시안)에는 아직 남아 있음 — 별도 확인 필요(요청서 3쪽).

**3. 원료 단품 판매**
- `catalog.js` 신설: 원료 12종(상태 soon/open/soldout, 중량 10g·50g·100g·200g·1kg별 가격, 우리는 온도·시간, 향·맛 한두 줄, 이야기), 레시피 9종, 교육 품목 4종. 원료 추가·품절·가격은 이 파일만 고친다.
- `ingredients.html`(원료 목록): 상태 배지, 중량 옵션, 버전·상태 필터, 원료별 「입고 알림 신청」.
- `ingredient.html?id=<원료>`(단품 상세): 사진 · 향·바디·여운 · 중량별 가격표(소비자가 + 강사 등급가 30·40·50% 미리 보기) · 우리는 온도·시간 · 이 원료가 들어가는 추천 블렌드(레시피 링크) · 이전/다음 원료. 효능 문구 없음.
- 강사 등급가는 로그인·승인 없이 「가격 보기」 선택으로 미리 보기. 실제 회원 등급 표시·결제는 쇼핑몰 연동 때.
- 가격이 미정인 중량은 「가격 미정」. 「원료 낱개 판매는 순서대로 열립니다」 문구 유지.

**4. 신규 페이지**
- `education.html`(교육): 교육 재료·자료 품목 목록(수업용 키트 · 블렌딩 노트 · 교재 · 수업용 원료 리필, 가격 미정) + 강의 문의 연결.
- `partners.html`(강사): 파트너 혜택(등급별 할인가 · 교육 자료 · 강의 연결) + 가입 신청 폼(검토 후 승인) + 강의 의뢰 문의 폼(기관·개인). 접수 서버 전까지 메일 앱으로.

**5. 기타**
- 이소연 대표 소개는 메인·블렌딩에서 빼고 「브랜드 이야기」 안쪽에 작게.
- 카카오 채널은 「연결 예정」 표기. 「가격·구성은 와디즈 리워드 기준이며 확정 전」 문구는 판매가 확정 후 수정.

**대표가 추가로 주실 것(요청서 4쪽)** — 교육 재료·자료 품목과 가격, 원료별 중량 옵션 가격. 들어오면 `catalog.js`만 채운다.
